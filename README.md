# Avishka Sewwandi — Portfolio Website

A responsive dark-theme software developer portfolio built with HTML5, CSS3, JavaScript and Bootstrap 5.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. An internet connection is needed for Bootstrap and Google Fonts CDN resources.

## Customize before publishing
- Add a professional headshot if desired (replace the initials card in `index.html`).
- Add direct GitHub repository links to each project after confirming the correct public repository URLs.
- Add a CV PDF and link a download button if you want one.
- Check all contact details and project descriptions before publishing.

## Publish free
You can publish this static website with GitHub Pages:
1. Create a GitHub repository named `yourusername.github.io` (or any repository).
2. Upload `index.html`, `styles.css`, `script.js`, and this README.
3. In repository Settings → Pages, select the main branch and root folder.
4. Save and wait for the published URL.

No React, build tools, or backend are required.
